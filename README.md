# Kreafy Creator Studio

**Status: Planning only. No application code or working AI engines have been implemented.**

Local-first, all-in-one AI video production studio for YouTube and Facebook automation creators. Original product inspired by AutoCut AI Suite, AutoCut Studio, ClipNova and StickStudio feature categories.

## Approved decisions
- Pure localhost website; future distributable copies with safe verified updates.
- Dark premium AutoCut AI Suite-inspired dashboard with colorful tool cards.
- Six navigation items: Dashboard, Projects, All Tools, Media Library, Templates, Settings.
- **Studios + Tools Together:** studio cards and standalone quick tools that open corresponding tabs, not duplicate backends.
- Free/open-source-first with opt-in, cost-aware cloud AI.
- Antigravity for initial development; GitHub/AGENTS.md and handoff for other agents.
- All modules must become genuinely functional with real end-to-end media tests.
