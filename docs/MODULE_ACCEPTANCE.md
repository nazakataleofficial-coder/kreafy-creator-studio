# Module Acceptance Baseline

For each studio/action: (1) real input imported; (2) chosen model/engine supports requested task; (3) processing tracked honestly; (4) output file is valid and previewable; (5) metadata and provenance saved; (6) user can save/reopen/reuse result; (7) failed or interrupted operations are recoverable; (8) existing projects/regressions remain functional; (9) licenses and credentials remain secure.

## Specific gates
VoiceForge: timed transcription, correct SRT, valid TTS audio, consent for voice cloning.
StoryCraft: editable structured scripts, tracked revisions and prompts.
VisualForge: batch images linked to scene references and safe aspect ratios.
CineCut: save/reopen/edit/MP4 render, sync captions/audio.
ClipForge: credible highlight candidates, review and aspect-aware export.
Documentary Director: 2-minute real video end-to-end and per-scene rework.
Motion: real supported output, no fake GPU capability.
Render Studio: playable videos, errors, queued jobs, interrupted recovery.
Asset Vault: search and cross-project usage alerts.
