# Security, Privacy, Licensing & Trust

## Security
Use loopback-only local server with origin and authorization protection; validate uploads, sizes, media formats and local paths; no arbitrary remote execution, unrestricted shell tools or browser secret exposure. Security test localhost CSRF, path traversal, upload bombs and secrets in logs.

## API credentials
Masked UI, OS-protected storage; explicit user consent on paid generation; per-provider policy/quotas and data privacy. Do not commit secrets, tokens or personal media to GitHub.

## Licenses
Audit repo licenses, model weights and individual dependencies before copying/integrating/distribution. VoiceStudio AGPL-3.0 requires particular legal review; FFmpeg is build/config dependent; model licenses may differ; Remotion commercial licensing limitations require attention. Competitor videos are research references, not a license to copy proprietary code or branding.

## User rights
Licensed music/fonts/visual assets, image/model rights metadata, permission-based voice cloning; avoid unauthorized likeness cloning. Deletion includes reversible trash and warnings for shared assets.

## Updates
Verified release integrity, backup pre-migration, compatibility check, transaction/rollback on failure; preserve local user data across updates.
