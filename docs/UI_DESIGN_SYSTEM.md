# UI Design System — approved direction

## Locked principles
AutoCut AI Suite-inspired dark, professional, colorful modular launcher; **do not copy copyrighted/proprietary assets or pixel-for-pixel layouts**. Six permanent sidebar pages, Option A Studios + Tools Together. Desktop-first.

## Proposed (not individually approved) tokens
Background #0D1420; cards #172235; primary action gold #D8B46B; primary text #FFFFFF; muted #ADBBD0. Studio accents: VoiceForge teal; StoryCraft purple; VisualForge blue; CineCut red; ClipForge orange; Documentary indigo; Motion pink; Asset Vault green; Render gold.

## Dashboard
Top bar brand/search/Quick Create/alerts; hero with create/import; nine colorful studio cards; quick tools for Transcribe, TTS, Generate Images, Auto Captions, AI Clipper and Video Generation; recent projects; active jobs; real system/engine status. No fabricated stats or subscription perks.

## Pages
- Projects: card/list, create, resume, filters, status, versions; in-project Overview, Script, Storyboard, Assets, Editor, Exports, Activity.
- All Tools: studio and individual tool views, categories, search, actual readiness and inputs/outputs.
- Media Library: videos/images/audio/subtitles/exports, asset inspector, usage links, favorites, duplicate detection, safe trash.
- Templates: documentary/Shorts/Reels/animation/podcast workflows, preview, customization, creator presets.
- Settings: general, local engines, cloud providers/keys, audio/video, hardware, cache/storage, backups, diagnostics, safe updates.

## UX requirements
Real error/loading/empty states, keyboard navigation, accessibility, undo and autosave; destructive-action confirmation, responsive non-editor surfaces. Protect approved screenshots through visual regression tests when implementation starts. All sample jobs, quota levels and storage figures in artwork are fictional.
