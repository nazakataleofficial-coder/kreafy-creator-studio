# Free-first engine research — candidate list, NOT integrated

| Source | Potential benefit | Caveat |
|---|---|---|
| https://github.com/zhouxiaoka/autoclip | Automatic highlight selection/clipping | Run code/license/runtime review |
| https://github.com/mutonby/openshorts | Clip detection, 9:16 reframing, captions, Docker pipeline | Many advanced functions require Gemini/fal.ai/ElevenLabs keys |
| https://github.com/debpalash/VoiceStudio | Voice cloning, dubbing, TTS, local API | AGPL-3.0: redistribution and integration obligations |
| https://github.com/OpenCut-app/OpenCut | Video editor architecture | Main repo undergoing rewrite; classic version evaluate |
| https://github.com/krillinai/OpenCreator | Multi-tool creator workflows and agents | Some features in development; requires configured model access |
| https://github.com/asjnaang/Image-Generator | Offline/batch image generation | Verify claims, model licenses, Windows hardware performance |
| https://github.com/hexgrad/kokoro | Lightweight TTS | Validate Urdu and 8 GB CPU performance |
| https://github.com/ggml-org/whisper.cpp | CPU-local transcription | Word accuracy and timing must be measured |
| https://github.com/SYSTRAN/faster-whisper | Optimized Whisper inference | Benchmark memory and language accuracy |
| https://github.com/m-bain/whisperX | Forced alignment, diarization | More demanding; language limitations |
| https://github.com/snakers4/silero-vad | Speech/silence detection | Verify orchestration |
| https://ffmpeg.org | Media rendering/compositing | Build/license/codecs review |

Never equate open-source code with unrestricted commercial redistribution; code and model licenses may differ. Microsoft Edge TTS is an online convenience, NOT a guaranteed unrestricted commercial API. Remotion licensing needs separate commercial-use check. Local heavy diffusion/video models may not be practical on the target CPU-only PC.
