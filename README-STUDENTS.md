# Kreafy Creator Studio — v0.14.0

**Roman Urdu (pehle ye parhain) — English below.**

## Shuru kaise karein? (3 steps)

**Step 1 — Python install karein (sirf EK dafa)**
- python.org se **Python 3.11 ya naya** download karein.
- Install karte waqt **"Add Python to PATH"** par tick ZAROOR lagayen.
- Bas — Node.js install karne ki zaroorat NAHI hai.

**Step 2 — App kholein**
- Folder me **`Start Kreafy Studio.bat`** par double-click karein. Bas yehi ek cheez bahar hai.
- Pehli dafa thora time lagega (packages install honge), phir browser me dashboard khul jayega.
- Band karna ho to jis window me app chal rahi hai us me **Ctrl+C** dabayen.

**Step 3 — Setup button dabayen**
- Dashboard khulne par upar **Setup — Install Requirements** ka banner aayega (ya Settings me jayen).
- Setup dabayen — wo khud install karega: backend packages, Chromium browser (Canvas free images ke liye), aur FFmpeg (video banane ke liye).
- Har step ke saath **green tick** aayega. Jab **"Ready"** likha aaye, app tayyar hai.
- **Desktop shortcut** bhi Setup se bana sakte hain — phir folder kholna hi nahi parega.

## Apni keys (FREE — har banda apni key lagaye)

- App **bina kisi key ke bhi chalti hai**. Jis feature ko key chahiye, wo saaf kahega "apni key dalo".

  - **Gemini — FREE** (script, research): aistudio.google.com
  - **Groq — FREE** (captions/transcription): console.groq.com
  - **OpenRouter — FREE** (script, Gemini na ho to): openrouter.ai

  - **Pexels / Pixabay — FREE** (stock photos/videos)
  - **Hugging Face — FREE** · **ElevenLabs — FREE** (10k characters/month)
  - **Deepgram — $200 TRIAL credit** (trial hai, hamesha free nahi)
  - **HeyGen / OpenAI — PAID**
- Keys **sirf aapke PC** par rehti hain. Kisi aur ki key kabhi use nahi hoti, aur update se keys kabhi delete nahi hotin.

## Videos kahan milengi?

- Aapki saari final videos **`output/`** folder me hain, tareekh ke hisaab se: `output/2026-11-22/apki-video_2026-11-22_1430.mp4`
- Settings me **Open output folder** se folder khul jata hai.

## Apna Main Character

- **Character Vault → "Apna Main Character Add Karo"**: apni character sheet image upload karein (ek sheet, ya front/side/back), naam + description likhein, niche chunein.

## Update kaise milega?

- **Settings → Check for Update** dabayen. Naya version aaye to ek click me update ho jayega.
- Update se aapki **videos, projects, settings aur keys kabhi delete nahi hotin** — sirf code badalta hai. Pehle backup banta hai; kuch ghalat ho to purana version wapas aa jata hai.
- Dashboard khulte hi **"Update available"** ka badge bhi dikhta hai jab naya version ho.

## Masla aaye to?

- Pehle **Settings → Setup** dobara chalain (wo missing cheez dobara install kar deta hai).
- Error message ko screenshot le kar apne teacher ko bhej dein — error me likha hota hai ke kya missing hai.

## English

### Start in 3 steps

**Step 1 — Install Python (once only)**
- Download **Python 3.11 or newer** from python.org.
- During install, tick **"Add Python to PATH"**.
- You do NOT need to install Node.js.

**Step 2 — Open the app**
- Double-click **`Start Kreafy Studio.bat`** in this folder. That is the only thing outside.
- The first run takes a while (packages install), then the dashboard opens in your browser.
- To stop, press **Ctrl+C** in the window where the app runs.

**Step 3 — Press the Setup button**
- A **Setup — Install Requirements** banner appears on the Dashboard (or go to Settings).
- Setup installs everything itself: backend packages, the Chromium browser (for Canvas free images), and FFmpeg (for video).
- Every step shows a **green tick**. When it says **"Ready"**, the app is ready.
- You can also create a **Desktop shortcut** from Setup — then you never need to open the folder.

### Your own keys (FREE — everyone uses their own key)

- The app **works with zero keys**. A feature that needs a key will plainly say "add your key".
- **Settings → Free keys** shows every key with a **FREE / TRIAL / PAID** badge and a link to get it:
  - **Gemini — FREE** (script, research): aistudio.google.com
  - **Groq — FREE** (captions/transcription): console.groq.com
  - **OpenRouter — FREE** (script fallback): openrouter.ai
  - **Pollinations — FREE, no key required** (images)
  - **Pexels / Pixabay — FREE** (stock photos/videos)
  - **Hugging Face — FREE** · **ElevenLabs — FREE** (10k chars/month)
  - **Deepgram — $200 TRIAL credit** (trial, not forever free)
  - **HeyGen / OpenAI — PAID**
- Keys stay **only on your PC**. Nobody else's key is ever used, and updates never delete your keys.

### Where are my videos?

- All final videos are in the **`output/`** folder, by date: `output/2026-11-22/your-video_2026-11-22_1430.mp4`
- **Open output folder** in Settings opens it.

### My Main Character

- **Character Vault → "Add My Main Character"**: upload your character sheet image (one sheet, or front/side/back), write a name + description, pick a niche.
- Then **Approve → Lock → "Set as my main character"**.
- After that, **the same character** appears in every video — its full description goes into every image prompt and its sheet is attached as the reference image.
- The built-in 70 characters stay as they are; your character lives separately under "my characters". You can replace or remove it any time.

### How do I get updates?

- Press **Settings → Check for Update**. If a new version exists, one click updates the app.
- An update **never deletes your videos, projects, settings or keys** — only the code changes. A backup is made first; if anything goes wrong, the old version comes back.
- The Dashboard also shows an **"Update available"** badge on startup when a new version exists.

### If something breaks

- Run **Settings → Setup** again first (it reinstalls whatever is missing).
- Screenshot the error message and send it to your teacher — the message says what is missing.
