# Universal AI Agent Rules

1. Read README.md, docs/PROJECT_STATE.md, docs/MASTER_PRD.md, docs/DECISIONS.md, docs/UI_DESIGN_SYSTEM.md, docs/HANDOFF.md and the relevant module spec before acting.
2. **Planning-only state. Do not code, install packages, deploy, run unknown EXEs or change approved UI without explicit owner authorization.**
3. Preserve six sidebar pages and the approved AutoCut AI Suite-inspired dark colorful **Studios + Tools Together** dashboard.
4. Never fake working features, progress indicators, providers, hardware numbers, metrics or testing results. Mockups are not proof.
5. Before substantive code changes inspect Git status, propose smallest scope and work in an isolated feature branch. Do not discard existing user changes.
6. Preserve source content, project data and assets; use safe migrations, backups, job checkpoints and scoped file permissions.
7. Use free/open-source-first tech, verify licenses and model rights; never commit API secrets or personal records.
8. Provider switching respects real quota scope, provider policies and explicit paid-API approvals; no quota evasion.
9. A feature is not complete without repeatable real input-to-output tests, regression evidence and a reviewed diff.
10. Update docs/PROJECT_STATE.md, docs/HANDOFF.md, feature matrix and decision log after approved work. Record actual commit, evidence, blockers and next task.
11. Documentation in technical English. Explain decisions to owner in simple Roman Urdu.
