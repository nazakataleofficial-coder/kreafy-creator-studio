# ClipForge AI — Long Video to Shorts

17 individual UI concepts. Each numbered .html has corresponding screenshots/NN_[slug].png. These are not working features.

- [ ] 01. Import Long Video — Local, Drive or authorized source upload and playback — Video source, Duration, File size, Language, Analysis type, Start
- [ ] 02. AI Analysis — Topic boundaries, speakers and candidate moments — Transcription, Topic shift, Speaker turns, Energy, Keywords, Engagement
- [ ] 03. Highlight Candidates — Time-coded candidates, reasons and editable scores — Score, Duration, Topic, Hook, Preview, Reject
- [ ] 04. Choose Shorts — Select candidate shorts and batch preview — Select all, Exclude, Reorder, Clip count, Duration, Review
- [ ] 05. Trim & Edit Short — Frame-accurate trim, split and reorder — Start time, End time, Trim, Split, Remove filler, Undo
- [ ] 06. Smart Reframe — 9:16 safe crop and face/speaker focus — Face track, Auto crop, Anchor, Padding, Keyframes, Safe area
- [ ] 07. Caption Designer — Word-level subtitles with highlight presets — Auto captions, Language, Font, Words per line, Animation, Position
- [ ] 08. AI B-Roll & Overlays — Context shots, logos and cutaway overlays — B-roll source, Overlay, Insert time, Duration, Scale, Rights
- [ ] 09. Brand Kit & CTAs — Channel logo, colors, intro/outro and CTA placement — Brand kit, Watermark, Logo, CTA, Social icons, Safe area
- [ ] 10. Clip Quality Review — Crop, audio, subtitle, content and duplicates checks — Black frames, Audio peaks, Caption cut, Duplicate, Safe crop, Approve
- [ ] 11. Shorts Export Presets — YouTube Shorts, Instagram Reels and Facebook formats — 9:16, 1080x1920, FPS, Codec, Caption burn, Watermark
- [ ] 12. Batch Queue — Multiple shorts queued, retry and progress status — Selected, Pending, Running, Failed, Resume, Output folder
- [ ] 13. Clip History — Compare clips and export revisions without re-analysis — Original, Version, Score, Export date, Reuse, Archive
- [ ] 14. First Run & Empty State — First-time setup, empty workspace and guided start — New project, Import media, Use template, Choose engine, Get help
- [ ] 15. Processing & Progress — Honest async job progress, cancellation and checkpoints — Queued, Running, Pause, Cancel, Checkpoint, Job history
- [ ] 16. Failure, Retry & Recovery — Actionable failure details, safe retry and output recovery — Error code, Failed step, View log, Retry, Change engine, Restore
- [ ] 17. Save & Export Confirmation — Preview, destination, overwrite protection and confirmation — File name, Destination, Version, Review, Approve, Export
