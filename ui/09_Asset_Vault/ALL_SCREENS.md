# Asset Vault & Brand Kits

15 individual UI concepts. Each numbered .html has corresponding screenshots/NN_[slug].png. These are not working features.

- [ ] 01. All Assets — Shared videos, images, voice clips, sound and subtitle items — Type, Search, Sort, Favorite, Used by, Collection
- [ ] 02. Folders & Collections — Organize reusable assets and smart collections — Folder, Tag, Collection, Smart filter, Add, Move
- [ ] 03. Project Asset Inspector — Technical metadata and every project that uses an asset — Dimensions, Duration, Hash, Original, Used by, Versions
- [ ] 04. Brand Kit Manager — Channel identities with logos, colors, typography — Logo, Primary color, Font, Watermark, Intro, CTA
- [ ] 05. Character References — Approved reusable character photos and appearance locks — Identity, Reference, Wardrobe, Styles, Project uses, Permission
- [ ] 06. Audio & SFX Collection — Browse voice, narration, licensed music and SFX — Narration, Music, SFX, Duration, License, Preview
- [ ] 07. Import Media — Safely import and index media with validations — Upload, Watch folder, File type, Tags, Project, Analyze
- [ ] 08. Duplicates & Missing — Detect duplicate media and disconnected paths — Hash, Duplicate, Missing, Used by, Relink, Archive
- [ ] 09. Safe Trash & Recovery — Recover deleted media before permanent cleanup — Trash, Dependencies, Restore, Retention, Delete, Audit
- [ ] 10. Usage & Provenance — Where each asset originated and how it was generated — Provider, Prompt, Model, Rights, References, Use in
- [ ] 11. Brand Preset Library — Shared typography, colors and outro/CTA templates — Brand, Style, Platform, Font, Watermark, Apply
- [ ] 12. First Run & Empty State — First-time setup, empty workspace and guided start — New project, Import media, Use template, Choose engine, Get help
- [ ] 13. Processing & Progress — Honest async job progress, cancellation and checkpoints — Queued, Running, Pause, Cancel, Checkpoint, Job history
- [ ] 14. Failure, Retry & Recovery — Actionable failure details, safe retry and output recovery — Error code, Failed step, View log, Retry, Change engine, Restore
- [ ] 15. Save & Export Confirmation — Preview, destination, overwrite protection and confirmation — File name, Destination, Version, Review, Approve, Export
