# StoryCraft Research & Writing

15 individual UI concepts. Each numbered .html has corresponding screenshots/NN_[slug].png. These are not working features.

- [ ] 01. Topic Research — Audience problems, competitive ideas and cited sources — Topic, Audience, Niche, Source type, Language, Research depth
- [ ] 02. AI Hook Generator — Create and compare multiple opening hooks — Hook type, Length, Emotion, Platform, Variations, Score
- [ ] 03. Outline & Structure — Long-form documentary structure and chapters — Hook, Problem, Conflict, Solution, CTA, Timing
- [ ] 04. Script Writing Workspace — Professional long-video writing with scene breaks — Style, Duration, Audience, Fact-check, Tone, Generate
- [ ] 05. Shorts Script Writer — 60-second shorts with word-budget and hook clarity — Platform, Length, Hook, Payoff, CTA, Hashtags
- [ ] 06. Prompt Library — Reusable prompts with categories, tags and versions — Prompt type, Template, Variables, Favorites, History, Copy
- [ ] 07. Visual Prompt Generator — Shot-by-shot visual prompts preserving references — Shot type, Lens, Lighting, Character lock, Aspect, Image model
- [ ] 08. Source & Fact Check — Trace assertions to references and review risk — Claim, Source URL, Confidence, Date, Approve, Reject
- [ ] 09. Script Version History — Track edits, compare script revisions and restore — Revision, Timestamp, Author, Differences, Restore, Branch
- [ ] 10. SEO & Publishing Pack — Title, description, chapters and platform adaptation — Title, Description, Chapters, Keywords, Thumbnail brief, Platform
- [ ] 11. Editor Review & Approvals — Manual script QA, flagged sections and signoff — Hook strength, Clarity, Claims, Pacing, Readability, Approve
- [ ] 12. First Run & Empty State — First-time setup, empty workspace and guided start — New project, Import media, Use template, Choose engine, Get help
- [ ] 13. Processing & Progress — Honest async job progress, cancellation and checkpoints — Queued, Running, Pause, Cancel, Checkpoint, Job history
- [ ] 14. Failure, Retry & Recovery — Actionable failure details, safe retry and output recovery — Error code, Failed step, View log, Retry, Change engine, Restore
- [ ] 15. Save & Export Confirmation — Preview, destination, overwrite protection and confirmation — File name, Destination, Version, Review, Approve, Export
