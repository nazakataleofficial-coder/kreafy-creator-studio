# StickMan & Whiteboard Animation

- [ ] 02. Scene Board — Scene list with visual continuity and timing — Add scene, Duration, Order, Duplicate, Transition, Scene status
- [ ] 03. Character Gallery — Choose or create unique stickman and whiteboard characters — Business, Casual, Teacher, Doctor, Custom, Favorites
- [ ] 04. Character Builder — Body, line thickness, accessories and palette — Head, Eyes, Body, Clothes, Colors, Accessories
- [ ] 05. Expressions & Lip Sync — Smile, concern, surprise and basic speech mouth shapes — Expression, Mouth, Blink, Eye direction, Timing, Reset
- [ ] 06. Actions & Poses — Walk, run, point, present, write and gesture — Idle, Walk, Point, Speak, Wave, Write
- [ ] 07. Whiteboard Canvas — Draw-order, hand reveal, pen colors and erase tools — Hand style, Draw speed, Pen, Background, Reveal, Eraser
- [ ] 08. Props & Icons — Searchable scene props, arrows, charts and visual icons — Chart, Laptop, Book, Arrow, Bulb, Import custom
- [ ] 09. Backgrounds & Themes — Whiteboard, paper, office and color themes — Theme, Gradient, Background, Border, Color, Grid
- [ ] 10. Motion Timeline — Scene length, action timing, ease and camera pan — Scene duration, Action track, Ease, Pan, Zoom, Loop
- [ ] 11. Voice & Lip Sync — Assign TTS/imported voice and align character speech — Voice, Script, Speaker, Sync, Volume, Pause
- [ ] 12. Preview & Export — MP4, transparent elements if feasible, captions — Aspect ratio, FPS, Resolution, Audio, Subtitles, Export
- [ ] 13. StickMan Templates — Classroom, explainer, finance and whiteboard templates — Category, Characters, Theme, Scenes, Customize, Save
- [ ] 14. First Run & Empty State — First-time setup, empty workspace and guided start — New project, Import media, Use template, Choose engine, Get help
- [ ] 15. Processing & Progress — Honest async job progress, cancellation and checkpoints — Queued, Running, Pause, Cancel, Checkpoint, Job history
- [ ] 16. Failure, Retry & Recovery — Actionable failure details, safe retry and output recovery — Error code, Failed step, View log, Retry, Change engine, Restore
- [ ] 17. Save & Export Confirmation — Preview, destination, overwrite protection and confirmation — File name, Destination, Version, Review, Approve, Export
